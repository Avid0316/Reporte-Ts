Cómo actualizar el informe
  1. Exporta del sistema los reportes ENTRADAS e Inventario tal como salen.
  2. Pulsa Cargar Excel y selecciona los dos archivos a la vez (o arrástralos aquí). La página reconoce cuál es cada uno y sus columnas.
  3. Elige el mes del informe y revisa la fecha de corte (se toma del nombre del archivo, por ejemplo Inventario_02.11.26).
  4. Para que todos vean el informe nuevo: pulsa Descargar datos.js y súbelo al repositorio en GitHub (Add file → Upload files), reemplazando el anterior.

El archivo publicado no guarda IMEI, proveedores ni conceptos: solo fecha, tipo, equipo, sucursal y cantidades.

Cómo consultar el inventario

Las cantidades corresponden al inventario del corte indicado. Puedes sumar todas las sucursales o consultar una en particular.

La agrupación por modelo y capacidad suma colores y versiones SIM. Menos de 5 incluye cero a cuatro unidades. Menos de 10 incluye cero a nueve. Los equipos con exactamente 10 unidades quedan fuera de ese filtro.

Las sucursales se unifican aunque estén escritas distinto (por ejemplo, «Nova Prisa», «NOVAPRISA» y «TechnologySales» cuentan como Novaprisa).

En la sección de cambios se usa el origen confirmado de cada movimiento.
