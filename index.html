Inventario general

Conexión con GitHub para guardar

Con la conexión, Guardar cambios publica los datos directamente y en 1–2 minutos todos los ven. Sin conexión, Guardar descarga el archivo datos.js para que lo subas a mano al repositorio.

  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y marca .
  3. En Permissions → Contents elige Read and write. Genera el token y pégalo aquí.

El token se guarda solo en este navegador. No lo compartas.

Cómo funciona
  1. Elige el mes arriba y pulsa Cargar Excel de entradas con el reporte de ENTRADAS del sistema (con la columna Cantidad).
  2. El inventario es uno solo para todo el informe: cárgalo cuando tengas un corte nuevo. La fecha de corte se toma del nombre del archivo (Inventario_02.11.26).
  3. Revisa el informe y pulsa Guardar cambios. Hasta entonces, lo cargado solo se ve en este navegador.

Los datos publicados guardan fecha, tipo, equipo, sucursal, cantidades y, en las compras, el proveedor (columna Referencia). No guardan IMEI ni conceptos.

Cómo consultar el inventario

Las cantidades corresponden al inventario del corte indicado. Puedes sumar todas las sucursales o consultar una en particular.

La agrupación por modelo y capacidad suma colores y versiones SIM. Menos de 5 incluye cero a cuatro unidades. Menos de 10 incluye cero a nueve. Los equipos con exactamente 10 unidades quedan fuera de ese filtro.
